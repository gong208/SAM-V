# SAM-V pinned dependencies.
#
# `segment_anything` (from the patched sam-hq fork) and `vggt` are NOT installed
# by pip. They come from the git submodules under submodules/, which are pinned
# to exact commits in .gitmodules and put on PYTHONPATH -- see the README's setup
# step 5. Earlier versions of this file carried them as `-e git+ssh://...`
# editable installs, which required SSH keys and pinned a different sam-hq commit
# than the submodule does.
#
# torch's CUDA wheels (nvidia-*-cu12, triton) are also not listed: they are
# transitive dependencies that pip resolves from the torch pin, and pinning them
# explicitly broke installs on CPU-only and non-Linux machines. These pins target
# Linux with CUDA 12.1; torch==2.3.1 pulls the matching runtime itself.
#
# timm is held at 1.0.22 deliberately. In 1.0.23 upstream removed RotaryEmbedding
# from timm.layers.attention_pool2d without updating its own timm.models.layers
# compatibility shim, which still imports it from there. sam-hq's
# segment_anything/modeling/tiny_vit_sam.py imports `from timm.models.layers
# import DropPath, to_2tuple, trunc_normal_`, so on 1.0.23 every entry point that
# builds the model dies at import with:
#   ImportError: cannot import name 'RotaryEmbedding' from
#                'timm.layers.attention_pool2d'
# 1.0.22 and every earlier release are fine. Do not bump this without importing
# masks/everything_mode_demo.py in a clean venv first.
